## 模板使用说明

### 填写规范

1. **概述**: 用一句话概括模块定位，列出所有类及其核心功能
2. **类定位**: 每类用一句话概括本质作用，给出典型使用流程代码示例
3. **核心方法**: 
   - 方法名用 `` 包裹
   - 必须包含输入输出表格
   - 用流程图/伪代码展示内部逻辑
   - 提炼关键点（1-3条）
4. **辅助方法**: 简化为表格，只列方法名、作用、补充说明
5. **数据流图**: 用ASCII图表展示关键流程
6. **常量**: 列出所有模块级常量
7. **使用示例**: 提供2-3个典型使用场景的代码

### 格式约定

- 类名用 **加粗**
- 方法名用 `` 包裹
- 类型名用 `{类型}` 格式
- 流程图用缩进的代码块
- 表格列对齐，内容简洁

### 内容取舍

**必须详细展开**:
- 类的核心方法（体现类本质目的的方法）
- 复杂内部流程
- 关键设计决策

**简要说明即可**:
- 参数设置类方法（get_params/set_params）
- 简单的 save/load
- 纯代理方法
